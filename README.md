# Lab Playground Repo

Welcome! This repo exists so you can practice **forking, cloning, and contributing**
without the stress of potentially breaking something.

## Getting Started

- **Install the dependencies.** `analysis.py` uses only the Python standard library (`csv`, `pathlib`), so you just need Python 3 installed. `analysis.R` uses only base R, so you just need R installed (e.g. via `conda install r-base`).
- **Run the analysis script.** From the repo root, run `python analysis.py` or `Rscript analysis.R`. Both load `data/sample.csv` and print a short summary.

## What's in here

This repo simulates a tiny, real-ish data science project:

- `data/sample.csv` — a small dataset
- `analysis.py` / `analysis.R` — a starter script that loads and summarizes it
- `.gitignore` — a working example of what to keep out of version control
- `LICENSE` — so you can see how licensing renders on a repo's landing page

Feel free to explore the structure of the repo before diving into the exercise below.
